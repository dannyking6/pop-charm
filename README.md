# Pop Charm 🫧

A classic bubble-shooter: aim, bounce and pop matching charms, clear the board
before the ceiling creeps down, and climb the levels — all in the browser, no
account, no internet needed.

**Genre:** arcade / bubble shooter
**Engine:** Tingly builder (custom canvas) · **Size:** ~3.8 MB · **Runs 100% offline**

## Controls

| Device | Action |
|---|---|
| Touch | Tap where you want to shoot — the launcher fires the charm |
| Mouse | Move to aim, click to shoot; press the swap button to switch charm |

## Run it

```bash
python3 -m http.server 8000
# then open http://localhost:8000
```
